# Original MATLAB code (transcribed)

The original `.m` files were lost. These files are a manual transcription of the
listings printed in section 3.2 (pp. 68-73) of the PhD thesis:

> N. Lavado (2012). *Extensões via splines da Análise em Componentes Principais*.
> PhD thesis, ISCTE-IUL. http://hdl.handle.net/10071/6202

They were checked line by line against the PDF pages but **have not been run in
MATLAB**. Accents in comments were dropped. The convergence test and the end of
the main loop are not printed in the thesis; the reconstructed lines are marked
`NOT IN THESIS`. A numpy port of these listings (`prototype/qlpca_prototype.py`)
reproduces thesis Tables 4.5-4.8.
